# Phase 1 — Foundation

FEW Quest is the shared competition platform for GrowMeal, GrowEnergy/GrowVolt and GrowAqua.

## Included now
- standalone Next.js application shell
- EN, HA, YO, IG, FR and AR localization foundation
- Arabic RTL
- isolated Supabase migration foundation
- profiles, schools, memberships, competitors, platform roles and audit events
- initial RLS helpers and policies

## Not yet included
Question-bank imports, Practice Arena engine, payments, 100 Cards, Hot Seat, Live 50, leaderboards or prize processing.

## Isolation rule
Never connect this repository to the existing GrowMeal production Supabase project. FEW Quest receives dedicated staging and production projects.
